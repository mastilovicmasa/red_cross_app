# Red Cross App

Mobilna aplikacija razvijena u okviru diplomskog rada za podršku organizaciji i praćenju aktivnosti Crvenog krsta. Aplikacija je namenjena različitim tipovima korisnika i obuhvata rad sa aktivnostima, korisničkim profilima, kompetencijama i opremom.

## Tehnologije

- `React Native`
- `Expo`
- `Expo Router`
- `Firebase`
- `Cloudinary`
- `TypeScript`
